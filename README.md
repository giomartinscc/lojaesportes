# 🛍️ Loja de Artigos Esportivos

Este é um projeto de uma **loja virtual de artigos esportivos**, onde o usuário pode navegar pelos produtos, selecionar variações (como o tamanho de camisas) e, ao realizar a compra, será redirecionado para o **Mercado Pago** para finalizar o pedido.

## 🚀 Tecnologias utilizadas

- **Node.js**
- **HTML e CSS**
- **TypeScript**
- **PHP**

## 🛒 Funcionalidades

- Exibição de produtos esportivos (ex: camisas, tênis, acessórios)
- Seleção de variação de produtos (ex: tamanho de camisas)
- Integração com o **Mercado Pago** para finalizar o pagamento
- Armazenamento e recuperação de dados no **Banco de dados**
